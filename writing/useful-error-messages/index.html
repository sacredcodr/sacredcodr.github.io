Give the error somewhere to go

Developer tools

A tool stops with Failed to open file. Which file? Was the path wrong, or was access denied? The message leaves you to investigate something the tool could have explained.

Keep the useful details

Where
The resolved path tells the reader which file the tool tried to open.
Why
Preserve the reported cause. A missing file and denied access need different responses.
What next
Suggest an action supported by that cause. If you don't know what failed, say so.

Leave room for diagnosis

Keep the first message readable. Put longer diagnostics in a log or an expandable section. Before asking someone to share a log, check for private paths, configuration values, and credentials.

A quick check

Try a missing file and a malformed configuration. Read only the output: can you tell where the operation stopped and choose a next step without opening the source?
