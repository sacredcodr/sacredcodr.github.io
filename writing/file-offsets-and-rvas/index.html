File offsets vs. memory addresses

Windows / PE

A location in a PE file can mean a position on disk or an address in memory. The number alone doesn't tell you which.

File offset
A byte position measured from the beginning of the file on disk.
RVA
A relative virtual address: a location in the loaded image, measured from its base.
VA
The virtual address in a process. Add the actual load base to the RVA.

A small example

Add the RVA to the image's actual load base to get its virtual address. Here is an illustrative calculation:

0x140000000Load base
+0x2100RVA
=0x140002100Virtual address

That calculation does not locate the bytes on disk. Sections have separate positions in the file and the loaded image; an RVA is generally not a file offset.

When reading a tool's output

Check which kind of address it displays before comparing numbers. If the image loads at a different base, the VA changes even when the RVA stays the same.

Reference: Microsoft's PE format specification.
